雲端架構參考實作

從 $0/月免費額度 起步、可直接演進至多帳戶多區域企業級的 serverless 架構: Terraform module 化、GitHub Actions OIDC 無金鑰部署、單表設計 DynamoDB、非同步 SQS 解耦。

架構總覽

CloudFront (OAC) → S3 靜態網站;/api/* → API Gateway HTTP API → Lambda(python3.13 / arm64)→ DynamoDB 單表設計;聯絡表單走 SQS → worker Lambda 非同步寫入, 失敗進 DLQ。全链路 CloudWatch + X-Ray 觀測,成本由 Budgets 三階告警與異常偵測把關。
